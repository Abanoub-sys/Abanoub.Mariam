# Abanoub & Mariam — Luxury Wedding Invitation

Open `index.html` in a modern browser. All photos and the supplied wedding music are included locally inside `assets/`.

Click the closed envelope to start the music and reveal the invitation. The music can be paused/resumed using the bottom-right control. The browser permits playback because the guest clicks the envelope first.

Wedding: Thursday, 12 November 2026, 7:00 PM, Virgin Mary Church in Zeitoun, Cairo.

To publish, upload **all files and folders** to a static hosting provider (Netlify, GitHub Pages, etc.). Keep the paths intact.

Fonts are loaded from Google Fonts when connected to the internet; local fallbacks are provided.
